# Sample Superstore Dataset Analysis

## Project Title
Sample Superstore Data Analysis Using Python Libraries

## Objective
The objective of this project is to analyze the Sample Superstore dataset using Python libraries and understand the sales and profit performance through basic data analysis and visualization.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## Dataset
- Dataset Name: Sample Superstore
- File Format: CSV

## Tasks Performed
- Imported the required libraries.
- Loaded the dataset using Pandas.
- Displayed the first five rows of the dataset.
- Checked dataset information.
- Checked missing values.
- Calculated the average sales using NumPy.
- Analyzed total sales by category using Pandas.
- Created a bar chart using Matplotlib.
- Created a scatter plot using Seaborn.
- Split the dataset into training and testing sets using Scikit-learn.
- Calculated the mean sales using SciPy.

## Output
The project successfully analyzed the Sample Superstore dataset and generated useful statistical information and visualizations.

## Conclusion
This project helped in understanding how Python libraries are used for data analysis, visualization, and basic machine learning operations. It also improved knowledge of handling real-world datasets in Google Colab.
